# 胶片工坊 / Film Studio

[中文](README.md) · [English](README.en.md) · **日本語**

**Sony a5100 / ILCE-5100 と a7R II / ILCE-7RM2** 向けの非公式フィルム調実験ツールです。[bonyback1 の Ricoh MOD](https://github.com/bonyback1/sony-pmca-ricoh-mod) のハードウェア色処理を参考にし、[富士フイルムが公開する GFX ETERNA 55 LUT](https://www.fujifilm-x.com/global/support/download/lut/) を色彩研究の参照資料として、写真と実験的な動画撮影に対応します。

## バージョン

- **現在のバージョン：`0.2.2-alpha`** —— リリースタグ `v0.2.2-alpha`、カメラ内表示は `0.2.2`（白点アンカー版は `0.2.2a`）。アプリ名：胶片工坊。
- **0.2.2 で追加したもの**：富士参照10種と上流のリコー／ストリート風5種に加えて、ライカ Look 参照スタイルを2種（クラシック、ナチュラル）追加し、**合計17種類**になりました。メニューは「富士」「理光」「ライカ」の接頭辞で区別します。パッケージと署名証明書は維持しているため、上書き更新できます。
- **今回のダウンロード版には 2026-09-14 の修正も2件含みます：**
  1. **フィルター選択画面でアプリが固まる問題。** 中央ボタンで開いたフィルター選択画面で MENU を押すと、画面は閉じたのにメニュー状態がスタックに残り、以降どのキーにも反応せず電源再投入が必要でした。修正済みで、a7R II で数十回の往復動作を確認しています。
  2. **富士系スタイルの彩度が高すぎる問題。** 近似の基準は富士のフラットな中性参照ですが、機体が行列へ渡すのは自前の Standard レンダリングで、彩度が約 1.26 倍あります。そのため色度ゲインが二重に掛かっていました。実写に基づいて校正し、100% 強度での参照 look との残差は 27% から約 **7.5%** に下がっています。
- 戻すための [0.1.3-alpha](https://github.com/ukiki0718-netizen/sony-a5100-film-studio/releases/tag/v0.1.3-alpha)（上流リポジトリ）も引き続き公開しています。

計測の詳細は[検証記録](docs/VALIDATION.md)を参照してください。

## 対応機種

**本プロジェクトで実機確認したのは a5100 と a7R II です。すべてのソニー製カメラで使えるわけではありません。**

| 機種 | 本プロジェクトでの状況 |
| --- | --- |
| **a5100 / ILCE-5100、ファームウェア1.10** | 実機確認済み。機能とバージョンの範囲は下記「検証範囲と制限」を参照 |
| **a7R II / ILCE-7RM2、Android 4.1.2 / API 16** | 導入・起動、および「中央ボタンでフィルター選択を開く → MENU で撮影画面に戻る」の往復動作を確認（2026-09-14）。本機は RGB 行列と拡張 Gamma テーブルに**非対応と報告**しますが、実測では**どちらも適用されます**：機体自身の STD JPEG を「行列＋カーブ」モデルに入れると実写と −1.3% まで一致し、カーブが飛ばされていれば一致しません。本機が**採用しない**のは Creative Style と Picture Effect の書き込みです（「全フィルターが同じ絵になり、ACROS までカラーになる」という症状で確認）。そのため現在は行列とカーブを**無条件に一緒に書き込みます**。以前の版は能力照会の結果だけで拡張 Gamma テーブルを飛ばし、look の半分である行列だけが適用されて画面が青緑に傾いていました（空が青緑、日射の当たる壁が緑、アプリを終了すると戻る）。現在は修正済みです |
| a6000、a6300、a6500 | 上流で挙げられた PMCA 対応候補。本バージョンは未検証 |
| a7、a7R、a7S、a7 II、a7S II | 上流で挙げられた PMCA 対応候補。本バージョンは未検証 |
| RX100 III／IV／V、RX10 II／III、RX1R II、HX90 | 上流で挙げられた PMCA 対応候補。本バージョンは未検証 |
| a6400、a6700、a7 III、a7C | 本アプリが必要とする PlayMemories Camera Apps の導入方式に非対応 |
| その他の機種・ファームウェア | 未評価。近い型番だけで互換性は判断できません |

候補は[上流プロジェクトの機種一覧](https://github.com/bonyback1/sony-pmca-ricoh-mod/blob/7c565898562c73c5073c54dfc831c8c3df9c24cf/README.md)に基づき、本プロジェクトで追加した動画・強度機能の実機結果ではありません。PMCA は必要なカメラ内アプリ基盤です。MTP やスマートフォンからの遠隔操作に対応しているだけでは、PMCA 対応とは判断できません。

**現在の動画メニューは a5100 の仕様に基づき、4K の選択肢はありません。** 他機種の全形式・フレームレート・ビットレートへの対応は保証しません。導入できた場合も、プレビュー、フィルター選択、JPEG 保存、録画開始／停止、保存動画の再生、終了後の色設定復帰を個別に確認する必要があります。機種によって実際の色も異なる可能性があります。報告には機種、ファームウェア、アプリのバージョン、確認した項目を記載してください。

## ダウンロードとインストール

**[APK を直接ダウンロード：0.2.2-alpha（ライカスタイルを追加）](https://github.com/Chai-Yu/sony-a7r2-film-studio/releases/download/v0.2.2-alpha/FilmStudio-0.2.2-alpha-movie.apk)** · [リリース説明](https://github.com/Chai-Yu/sony-a7r2-film-studio/releases/tag/v0.2.2-alpha)

- ファイル：`FilmStudio-0.2.2-alpha-movie.apk`（3,789,781 バイト）— 既定の `faithful` 処理
- SHA-256：`5a6417043e9fe9bba470f7d10d61440c1227a10ba835734748b325e43c752ad3`
- **白点アンカー**版：`FilmStudio-0.2.2-alpha-movie-leica-anchor.apk`（3,790,896 バイト、SHA-256 `c5ebc6799258dfbc091657902bbb593e01ad7d1d737738d9a469a211e7e2f0c2`）— 白を白のまま保ち、全体を暗くしません。**両版の違いはライカのトーン出力のみ**で、行列は共通です。どちらを使うかは実写での見ての判断になります。

[日本語の導入手順](docs/INSTALL.ja.md)に沿って導入してください。自分でビルドする必要はありません。**入れて使うだけの人は「方法 A」**：カメラの USB モードを MTP にし、pmca-gui で APK を選んで導入します。開発者モードもコマンド操作も不要です。**Code → Download ZIP はソースであり、インストーラーではありません。**

これは非公式の実験版で、実機確認は上記の a5100 と a7R II に限ります。APK には Sony の基礎アプリと公開された富士フイルム LUT から近似したパラメータを含みます。これら第三者資料の改変・再配布について個別の許諾は未確認です。公開は Sony／FUJIFILM の許諾や免責を意味しません。各部分の権利は[ライセンスの適用範囲](LICENSING.md)を参照してください。公式の元 LUT ファイルと署名秘密鍵は配布しません。

適法にビルドした APK があり、カメラの Wi-Fi ADB が有効な場合：

```sh
adb connect CAMERA_IP:5555
adb -s CAMERA_IP:5555 install -r output/FilmStudio-0.2.2-alpha-movie.apk
```

**IP アドレスとプライバシー：** `CAMERA_IP` は仮の表記です。Tweak → Developer で自分のカメラに現在表示されている IP アドレスに置き換えてください。仮の表記をそのまま入力したり、他人のアドレスをコピーしたりしないでください。末尾のポート `:5555` はそのままにします。公開手順には仮の表記を使い、スクリーンショットやログを共有する際は実際の IP アドレスを隠すか削除してください。

手順の全体は[日本語インストール手順](docs/INSTALL.ja.md)にあります：入力資料の準備 → ローカルビルド → USB（pmca-gui）／Wi-Fi ADB インストール → 操作 → 更新・トラブル対応。初回は説明書の準備作業も必要です。

### APK を受け取った人もビルドが必要ですか？

**不要です。署名済み APK は説明書の方法でインストールできますが、動作可否は機種と環境に依存します。** インストールだけなら Python、Java、Apktool、署名秘密鍵は不要です。自分で改変・生成する場合だけローカルビルドの章を参照します。ビルドしたこと自体で第三者の許諾が得られるわけではありません。

## 機能

- 富士フイルム公式 LUT を参照した10種類：PROVIA、Velvia、ASTIA、CLASSIC CHROME、REALA ACE、PRO Neg. Std、CLASSIC Neg.、ETERNA、ETERNA BLEACH BYPASS、ACROS。
- 上流のリコー／ストリート風5種：GR ポジ、ネガ、ハイコントラスト白黒、森山風、クロスプロセス。コミュニティのスタイルであり、リコー公式 LUT ではありません。
- ライカ Look 参照スタイル2種：クラシック（Classic）、ナチュラル（Natural）。SL2-S 公式 L-Log LUT から近似しましたが、**ライカは中性参照 LUT を提供していない**ため、基準レンダリングは本プロジェクトが L-Log 仕様に沿って構成したもので、ライカ公式プリセットではありません。
- 写真プレビューと動画待機中に、中央ボタンでフィルターを選択。
- MENU 1ページ目 →「滤镜强度」（強度）：**30% / 50% / 70% / 100%**。初期値は70%。写真と動画で共通、通常終了時に設定を保存します。**100% がそのフィルター本来の look です。**
- MENU 1ページ目 →「拍照／录像模式」→ 動画 P/A/S/M を選び、「录像文件格式」（形式）と「录像帧率／画质」（フレームレート／画質）を設定。機種が対応する XAVC S / AVCHD / MP4 と現在の PAL/NTSC 設定に従います。
- MOVIE ボタンで録画開始／停止。録画中はフィルターと強度を変更しません。
- ホワイトバランスは MENU 4ページ目で調整できます。基準は STD/スタンダード、コントラスト・彩度・シャープネスは0。アプリ内でポートレートやビビッドを重ねる設定にはしていません。
- パッケージ名は `com.yuki.imaging.app.pictureeffectplus`。元の Ricoh MOD と共存できます。

人物撮影では、まず30%と70%を比較してください。カラー系の強度は色変換と明暗カーブを弱めるもので、顔検出や肌色の自動補正ではありません。

**ACROS、リコーのハイコントラスト白黒、森山風はどの強度でも色を持ちません**：強度が下げるのはコントラストだけで、100% がそのフィルター本来のコントラストです。

## 検証範囲と制限

実機確認は次の2機種で行っており、他機種の動作は保証しません。

- **a5100 / ILCE-5100、ファームウェア1.10、Android 2.3.7 / API 10**：3×3 RGB 行列と拡張 Gamma テーブルに対応し、本プロジェクトが近似したハードウェア色パラメータを使用します。
- **a7R II / ILCE-7RM2、Android 4.1.2 / API 16**：上記2項目に非対応と報告しますが、実測では**どちらも適用されます**。そのため本機でも近似パラメータを使用します。採用されないのは Creative Style と Picture Effect の書き込みで、詳細は[ライブビューの説明](docs/LIVE-PREVIEW.zh-CN.md)を参照してください。

バージョン履歴：

- 0.1.1：10種類の選択、PROVIA のカラー JPEG、ACROS の白黒 JPEG、ACROS の XAVC S 1080p59.94 動画の保存と全体のデコードを確認。
- 0.1.2：形式・画質メニューを操作できるとの利用者確認あり。すべての形式の保存ファイルを分析したわけではありません。
- 0.1.3：インストール、起動、初期フィルター適用を確認。新しい操作について利用者の総合的な確認あり。全フィルター・強度・形式の組み合わせは未検証です。
- 2026-09-14（a7R II）：インストール、起動、および「中央ボタンでフィルター選択を開く → MENU で撮影画面に戻る」の往復を数十回行い、すべて正常でした。この経路は以前アプリの状態管理を固まらせ（画面は閉じたがメニュー状態が残る）、以降どのキーにも反応せず電源再投入が必要でしたが、修正済みです。同じ日に、実写3連カット5組から富士系の彩度校正も完了しました（[検証記録](docs/VALIDATION.md)を参照）。a5100 ではこれらの修正を再確認しておらず、両機種とも本版の保存ファイルと色は未検証です。

**アプリ内の再生画面には現在、写真だけが表示されます。** 動画はアプリを終了し、カメラ標準の再生画面で対応する XAVC S / AVCHD / MP4 の表示モードを選んでください。

**近似の限界：** 富士フイルムのフィルムシミュレーションを完全移植したものではありません。F-Log2/F-Gamut LUT を通常のソニー映像へ直接適用せず、WDR-709 を代替の中性基準として3×3行列と1024点の共通カーブに近似しています。**彩度特性は a7R II の実写 5 シーン（各シーンとも機体 Neutral／機体 STD／アプリ出力、うち 2 シーンは 100% 強度）で校正しています。** 彩度以外の限界は残ります：a5100 は未校正、粒状感やセンサー特性は再現せず、近似誤差が大きいスタイルもあり、**減彩系スタイル（特に REALA ACE）への補正はまだ方向が逆です**。
