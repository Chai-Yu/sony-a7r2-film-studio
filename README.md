# 胶片工坊 / Film Studio

**中文** · [English](README.en.md) · [日本語](README.ja.md)

面向 **Sony a5100 / ILCE-5100 与 a7R II / ILCE-7RM2** 的非官方胶片风格实验工具。参考 [bonyback1 的 Ricoh 模组](https://github.com/bonyback1/sony-pmca-ricoh-mod) 的硬件色彩处理方法，并以 [富士公开的 GFX ETERNA 55 LUT](https://www.fujifilm-x.com/global/support/download/lut/) 为色彩研究参考，提供照片与实验性录像效果。

## 版本

- **当前版本：`0.2.2-alpha`** —— 发行标签 `v0.2.2-alpha`，相机内版本名 `0.2.2`（白点锚定变体为 `0.2.2a`）。应用名称：胶片工坊。
- **0.2.2 新增**：在 10 个富士参考与 5 个上游理光／街头风格之外，新增 2 个徕卡 Look 参考风格（经典、自然），共 **17 个**；相机菜单以「富士」「理光」「徕卡」前缀区分。包名与签名沿用旧版，可覆盖更新。
- **本次下载版另含 2026-09-14 的两项修复：**
  1. **滤镜菜单卡死** —— 从确认键打开滤镜菜单后再按 MENU，界面关闭却把菜单状态留在状态栈上，之后任何按键都不再响应，只能关机恢复。已修正，并在 a7R II 上连续数十次往返验证。
  2. **富士家族过饱和** —— 拟合基准用的是富士扁平的中性参考，而机身实际送入矩阵的是它自己渲染过的 Standard 画面（色度高约 1.26 倍），色度增益因此被叠乘。现已按实拍标定：100% 强度下与官方 look 的残留偏差从 27% 降到约 **7.5%**。
- 更早的 [0.1.3-alpha](https://github.com/ukiki0718-netizen/sony-a5100-film-studio/releases/tag/v0.1.3-alpha)（上游仓库）仍保留供回退。

## 功能

- 10 种富士官方 LUT 参考风格：PROVIA、Velvia、ASTIA、CLASSIC CHROME、REALA ACE、PRO Neg. Std、CLASSIC Neg.、ETERNA、ETERNA BLEACH BYPASS、ACROS。
- 5 种上游理光／街头风格：GR 正片、负片、高反差黑白、森山风、正负逆冲。来自社区模组，非理光官方 LUT。
- 2 种徕卡 Look 参考风格：经典（Classic）、自然（Natural）。由 SL2-S 官方 L-Log LUT 拟合；但**徕卡不提供中性参照 LUT**，基准渲染由本项目按 L-Log 规范构造，因此不是徕卡官方预设。
- 拍照及录像待机时，按中心键进入滤镜选择。
- MENU 首页 →「滤镜强度」：**30% / 50% / 70% / 100%**。初始为 70%，拍照与录像共用，正常退出后保存选择。**100% 即该滤镜的完整 look。**
- MENU 首页 →「拍照／录像模式」→ 动态影像 P/A/S/M，再设置「录像文件格式」及「录像帧率／画质」。显示相机支持的 XAVC S / AVCHD / MP4 组合，不强行开放另一 PAL/NTSC 制式。
- 按 MOVIE 开始／停止录像；录制过程中固定滤镜与强度。
- MENU 第 4 页可调整白平衡。滤镜以 STD 标准、对比度／饱和度／锐度为 0 作为基础，应用内不叠加原机人像、鲜艳等创意风格。
- 独立包名 `com.yuki.imaging.app.pictureeffectplus`，可与原 Ricoh 模组共存。

人像可先比较 30% 与 70%。彩色滤镜的强度同时减弱色彩矩阵与明暗曲线，并不识别人脸或自动校正肤色。

**ACROS、理光高反差黑白和森山风在任何强度下都不带色彩**：强度只降低对比度，100% 即该滤镜的原始对比度。

## 已验证范围与限制

实机测试在两类机身上进行，均不承诺其他机型兼容：

- **a5100 / ILCE-5100，固件 1.10，Android 2.3.7 / API 10**：机身支持 3×3 RGB 矩阵与扩展 Gamma 表，使用本项目拟合的硬件色参数。
- **a7R II / ILCE-7RM2，Android 4.1.2 / API 16**：机身报告不支持上述两项，但实测矩阵与扩展 Gamma 表**都被采纳**，因此同样使用本项目拟合的参数；被忽略的是 Creative Style 与 Picture Effect 写入，见[实时取景说明](docs/LIVE-PREVIEW.zh-CN.md)。

版本记录：

- 0.1.1：10 个风格菜单成功切换；PROVIA 彩色与 ACROS 黑白 JPEG 正常保存；ACROS XAVC S 1080p59.94 视频成功保存并完整解码。
- 0.1.2：录像格式和画质菜单获得用户可用性确认；尚未逐一分析所有格式生成的文件。
- 0.1.3：安装、启动及默认滤镜应用已验证，中心键与强度操作得到用户总体确认；未逐一检验每种风格、强度、录像格式的最终文件。
- 2026-09-14（a7R II）：安装、启动，以及「确认键打开滤镜菜单 → 按 MENU 返回拍摄界面」连续数十次往返全部正常。该路径此前会卡死应用状态机（界面已关闭，菜单状态却未弹出），之后任何按键都不再响应、只能关机恢复，现已修复。同日还按五组实拍三连照完成了富士家族的色度标定（见[验证说明](docs/VALIDATION.md)）。a5100 未重测这些修复；两机的照片／录像保存与色彩均未在本版验证。

**应用内回放目前只显示照片。** 查看录像请退出应用，进入原机回放，并选择与文件对应的 XAVC S / AVCHD / MP4 观看模式。

**数值近似的边界：** 这不是富士机内胶片模拟的完整移植——官方 F-Log2 / F-Gamut LUT 不能直接套在普通索尼画面上。本工具以 WDR-709 为替代中性参考，拟合 3×3 颜色矩阵与 1024 点共同曲线，**色度已用 a7R II 实拍的五个场景（每个都含机身 Neutral／机身 STD／应用输出，其中两组为 100% 强度）标定**。色度之外的限制仍然存在：a5100 未实拍标定，不模拟颗粒或传感器响应，某些风格误差较明显，且**去饱和系滤镜（如 REALA ACE）的修正方向仍不正确**。
